## Usage

### Writing data

```python
from datetime import datetime
from zoneinfo import ZoneInfo
import numpy as np
from pynwb import NWBFile, NWBHDF5IO
from ndx_<name> import <TypeName>

# Create NWB file
nwbfile = NWBFile(
    session_description="Example session",
    identifier="example_001",
    session_start_time=datetime.now(ZoneInfo("UTC")),
)

# Create extension objects
obj = <TypeName>(
    name="example",
    # ... required fields
)

# Add to NWB file
nwbfile.add_acquisition(obj)  # or appropriate method

# Save
with NWBHDF5IO("example.nwb", "w") as io:
    io.write(nwbfile)
```

### Reading data

```python
from pynwb import NWBHDF5IO

with NWBHDF5IO("example.nwb", "r") as io:
    nwbfile = io.read()
    obj = nwbfile.acquisition["example"]
    print(obj.<field_name>)
```

### Step 4: Ensure Docstrings

Every public class and method should have a docstring:

```python
@register_class("MyType", NS)
class MyType(NWBDataInterface):
    """A custom neurodata type for storing <data>.

    This type extends NWBDataInterface and adds fields for <purpose>.

    Parameters
    ----------
    name : str
        Name of this object.
    signal : array-like
        The recorded signal, shape (num_times, num_channels).
    sampling_rate : float
        Sampling rate in Hz.
    description : str, optional
        Description of this object.
    device : Device, optional
        The recording device.
    """
```
